Why isolate a public security demo?

Public educational tools should never expose private logs, administrator credentials or third-party network targets. A fixed scenario catalog and synthetic telemetry make concepts inspectable without creating a network proxy.

Separate presentation from infrastructure. Treat all client input as untrusted, keep privileged operations behind authenticated APIs, and retain only necessary data.

From a request to a security event

A useful observability record contains a timestamp, a category, a severity and a decision. The demo below shows the shape of such a record, without identifying anyone.
